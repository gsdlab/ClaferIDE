Solution Generator

In this window, you can select, run, and control a solution generator.
  • Use the button "" to begin a session with the selected solution generator.
  • Use the button "" to kill a session with a running solution generator.
  • Use the button "" to get the next solution: an instance of a static model, or a trace of a dynamic model.
  • Use the button "" to show each next solution, or state of a trace, as its changes. It is on by default, and can be set before running.
  • Use the button "" to get another trace with the same states as the last trace before the given state.
  • Use the button "" to get a solution with another configuration: a trace with other final clafers, or an instance with other clafers, whatever their values.
  • Use the button "" to check the assertions of the model within the scopes and the maximum trace length: those on the line in the field next to the button, or all of them if it is empty or not positive. The console lists each assertion, and each one that fails gives a counterexample, which the Solution Graph shows.
  • Use the button "" to reload the model, preserving the scopes and other settings.
  • Use the button "" to finish the session safely.
  • Adjust scopes or Maximum Integer bound settings using "" or "" buttons.
