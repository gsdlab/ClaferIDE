Results

In this window, you can view the outputs of the compiler and the graph of the latest solution.
  • Use the "" drop down to select a result to show.
  • Solution Graph shows the latest instance, or the states and transitions of the latest trace. It is shown when a run starts, and updates with each solution. With Diff on, each state shows its changes.
  • Use the "Download link to download the selected output of the compiler.
